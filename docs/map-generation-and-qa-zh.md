# 地图生成与 QA 规范

## 双轨地图来源

### 有限解地图

Beginner 与 Advanced 各使用 8 张固定地图。固定地图不参与随机生成；每一张都需要：

1. 自动验证出生点、洞口、障碍净空、叶缘安全距离和可达路径。
2. 键盘完成一次通关、一次掉落恢复、一次错误颜色入洞。
3. 平衡垫人工完成一次通关，确认坡度、惯性和视觉提示。
4. 在 16:9 大屏和手机镜像画面中检查洞口、瓢虫与机关是否可辨认。

任何固定地图调整都视为单独内容变更，不能依赖生成器重摇来规避问题。

### 无限解地图

Endless 与 Rogue 使用相同的规则生成器。每张候选地图必须通过验证器，否则整张重摇；
重摇预算耗尽时，退回经过审核的固定地图变体，不能把未验证地图交给玩家。

硬性限制：

- 瓢虫出生点必须位于叶面内部、低坡度区域，且不与洞口或障碍重叠。
- 洞口周围保留捕获净空；洞口数不能超过必需瓢虫数。
- 障碍、露水和生态事件不得覆盖出生点或堵死全部路线。
- 分离叶片和岛屿地图中的每只瓢虫必须有可达目标。
- 同色归巢关中，每种瓢虫颜色必须存在对应洞口。
- 空降瓢虫每关最多 3 只；它们是奖励，不计入必需通关目标。
- 前 4 关不放置高认知负担事件；后续机制按难度窗口逐步解锁。

## Debug 验收

使用 `?qa=1` 打开游戏，点击右下角 `DEBUG` 或按 `F3`：

- 输入关卡号并加载任意程序化地图。
- 选择蜘蛛网、冰雹、宝箱、云雾、空降瓢虫、地鼠、尖刺、墨水或露水，面板会在
  当前 seed 的前 160 关中找到包含该机制的地图。
- `CAPTURE`、`DROP`、`NEXT`、`BUTTERFLY` 分别测试入洞、掉落、换关和辅助提示。

自动验证证明规则边界，人工 QA 负责判断地图是否有趣、信息是否看得懂；两者不能互相替代。
